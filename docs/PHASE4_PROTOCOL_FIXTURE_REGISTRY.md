# Phase 4 Protocol Fixture Registry
## frozen 2026-08-27

This registry is the authoritative index of protocol message fixtures used
by Phase-4 tests. Every fixture has a recorded source, a recorded commit or
tag, a SHA-256, and a license. No fixture is hand-invented to look
official.

Sources are live-verified official repositories and published spec URLs.
Fixtures are stored under
`services/api/tests/fixtures/phase4/` as canonical JSON (and, for binary
tokens, as separate files).

## Provenance check

A test in `tests/phase4/test_fixture_registry.py` reads every fixture
file, computes its SHA-256, and writes the result to a sidecar
`*.sha256` file under the same directory. A test-time re-read compares
the current file hash to the sidecar; mismatch fails the test (no
fixture is silently edited).
